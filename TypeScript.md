# What is TypeScript? Why is it the first preference for today's developers?

TypeScript is now one of the most essential parts of modern programming. A very common definition of TypeScript is that it is a superset of JavaScript. It was developed by Microsoft engineers. 

Before learning why we need another language when we have JavaScript, here are some real-world issues that emphasize the need for a type-strict language:

At the start of every project, JavaScript is the best choice for all developers. However, when your project goes into production, it has multiple files, multiple folders, and multiple variable objects. This makes it hard to track all of them and their data types.

Most senior developers have their own opinions on the importance of JS or TS.

When TypeScript was new, it was very hard for a well-settled community to learn and implement it in their upcoming projects. But slowly, it took its own space and made its place in the market today. Or, we can say, all major libraries and frameworks are supporting it.


TypeScript helps to make code more predictable, unlike JS. It provides type safety, so while developing, it is easy to share or understand what kind of response we need or what we are getting. It helps to catch bugs while writing code or before compile time, which helps to reduce errors or bugs incredibly fast.
